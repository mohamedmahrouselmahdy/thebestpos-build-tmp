# دليل أداة التراخيص: ذا بيست بوس (للمالك فقط)

الأداة: `dzpos-license.exe`. دي بتاعتك إنت بس. **متتبعتش للعملاء ومتتحطش جوه المثبّت.**

## 1) التجهيز (مرة واحدة بس)

1. نزّل `dzpos-license.exe` وحطه في فولدر، مثلا `C:\TheBestLicence\`.
2. افتح PowerShell في الفولدر ده وشغّل:

```
.\dzpos-license.exe keygen --keys "$env:USERPROFILE\TheBest licence key" --id k2
```

3. هيسألك على كلمة سر (passphrase). اكتب كلمة سر طويلة وحطها في مدير كلمات السر (Bitwarden مثلا). لو ضاعت مش هتقدر تصدر تراخيص.
4. هيعمل فولدر فيه:
   - `licence-signing.key` ← المفتاح الخاص. **سري. مش بيتبعت ولا بيتصور ولا بيترفع على سحابة.**
   - `licence-signing.pub` ← المفتاح العام. ده الوحيد اللي تبعتهولي.
   - `ledger.json` ← سجل بكل ترخيص أصدرته.
5. انسخ الفولدر على فلاشتين في مكانين مختلفين (المحل والبيت). امسح أي ملف اسمه `passphrase.txt` لو ظهر.
6. ابعتلي **المفتاح العام بس** (السطر اللي بيبدأ بـ k2 أو محتوى `licence-signing.pub`). أنا هحطه جوه البرنامج وأبني النسخة اللي بتتباع. من غيره أي ترخيص تصدره مش هيشتغل على النسخة.

## 2) إصدار ترخيص لعميل

1. العميل بيثبّت البرنامج. هتظهر له شاشة تفعيل فيها **كود الجهاز** شكله `DZPOS-XXXX-XXXX-XXXX-XXXX`. يبعتهولك (واتساب أو QR).
2. وضّح مكان الفولدر وشغّل:

```
$env:DZPOS_LICENSE_KEYS = "$env:USERPROFILE\TheBest licence key"

# تجريبي 7 أيام
.\dzpos-license.exe issue --device DZPOS-XXXX-XXXX-XXXX-XXXX --kind trial --customer "اسم العميل" --phone "01xxxxxxxxx"

# ترخيص دائم (بعد الدفع)
.\dzpos-license.exe issue --device DZPOS-XXXX-XXXX-XXXX-XXXX --kind lifetime --customer "اسم العميل" --phone "01xxxxxxxxx"
```

3. الأداة بتطلّع مفتاح يبدأ بـ `DZL1.` (ممكن كمان ملف `.dzlic` في فولدر `issued`). ابعته للعميل.
4. العميل بيلصق المفتاح في شاشة التفعيل (أو من الإعدادات > الترخيص) والبرنامج يفتح.

أوامر تانية: `list --device <الكود>` يعيد طباعة مفاتيح الجهاز، `inspect <المفتاح>` يفحص مفتاح، `revoke <رقم الترخيص>` يلغي ترخيص (بيوصل مع التحديث القادم).

## 3) القواعد

- **التجريبي 7 أيام**، مرة واحدة بس لكل جهاز. بعد ما يخلص **البرنامج بيتقفل بالكامل** لحد ما يتدخل مفتاح.
- **الدائم**: جهاز واحد، مرة واحدة، مفيش تجديد.
- المفتاح **متوقّع بتوقيع رقمي Ed25519**: مينفعش حد يخمّنه أو يألفه من غير مفتاحك الخاص.
- تغيير الويندوز أو القطع: كود الجهاز بيتغير، فالترخيص القديم بيقف والعميل لازم يرجعلك. بتصدر له كود جديد بـ `--replace <رقم الترخيص القديم>` (قرارك لو تاخد فلوس ولا لأ).
- البرنامج بيشتغل بالكامل من غير إنترنت.

## 4) احتياطات

- ضيّع الفلاشة + كلمة السر = مفيش تراخيص جديدة (القديمة تفضل شغالة). اعمل نسختين.
- متشغّلش `keygen` تاني بنفس الـ id.
